# Feature patterns (draft, from founder feedback 2026-10-19)

Writers miss features. In the fresh-pain audit the founder found 11 more on cards that already had some (see `../evaluations/generator-2026-10/founder-feature-ideas.md`). Before finishing a card, check each non-feature fix against these patterns and ask: what could It build that would make this easier, shared, ongoing or accountable?

| Pattern                          | What It does                                                                                  | Founder examples                        |
| -------------------------------- | --------------------------------------------------------------------------------------------- | --------------------------------------- |
| **Directory or lookup**          | Finds the program, group, rule, provider or official that applies to you, from public data    | Local loneliness activities (F6)        |
| **Private match at a threshold** | You say privately what you want; It connects you only once enough people nearby want the same | Neighbors who want to meet (F1)         |
| **Match people to needs**        | Matches skills, time or resources to groups that need them                                    | Work skills to local causes (F10)       |
| **Campaign organizing**          | Gathers people behind one specific ask, tracks who has signed on, sends it together           | Right-to-disconnect campaign (F3)       |
| **Pooled funding**               | Lets people and businesses fund something shared and see where the money goes                 | Funding a county reporter (F5)          |
| **Shared reporting**             | Neighbors split coverage, share sources and notes, and publish together                       | Citizen journalists (F4)                |
| **Answer service**               | Takes a person's question, finds a sourced answer and follows up                              | Straight local answers (F7)             |
| **Accountability record**        | Summarizes meetings and votes into a lasting record of who decided what                       | Meeting minutes by representative (F11) |
| **Clarifying follow-up**         | Asks a follow-up question later to narrow down what's going on, then adjusts the suggestions  | Work vs. management (F8)                |
| **Guided practice**              | Prepares you for a hard conversation or skill, then checks in on how it went                  | Family politics talks (F2)              |
| **Tracking and nudges**          | Tracks something you care about privately and nudges at the right moment                      | Pause before habit apps (F9)            |

Write features as features. A feature title names the capability, such as "Shared signup for covering town meetings". It doesn't name a user action like "Ask your state for…", which the founder flagged in a15: "The features need to be reworded to sound like actual features."
