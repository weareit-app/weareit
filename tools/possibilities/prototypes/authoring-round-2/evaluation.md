### Disagreements

1. **Subsidy boundaries.** A splits eligibility from approval. B treats submission as the result but approval as the outcome. C splits submission from the decision. Classification: **ambiguous guide wording** ("Apply" and "get approved" are named as different activities, but the guide doesn't say how to handle a result someone else decides). B's version is also an **authoring error**.
2. **Fix 3 as checklist or steps toward.** B calls it a checklist with the decision as the result; C calls it "not a checklist" with the same result; A uses agreement as the result. Classification: **ambiguous guide wording** (the checklist test when the result is "a decision received").
3. **Swap scope.** A uses regular care, B uses joined (with an unwritten second fix), and C uses a "join" title with regular care as the result. A and B are a **legitimate alternative**. C's title and B's missing fix are **authoring errors**.
4. **Nanny share.** A writes two fixes, B writes one fix ending at "agreed", and C writes one fix ending at "running". A and C are a **legitimate alternative**. B is an **authoring error**.
5. **Tuesday as a workday.** A has "not checked", B leaves it out, and C has "yes (inferred)". C's version is an **authoring error**, helped by the guide forbidding silence-to-"no" but not silence-to-"yes".
6. **Nearby family found.** A and B have "not checked"; C has "no (said)". Classification: **ambiguous guide wording**, since "I'd need to find" is neither silence nor a direct statement.
7. **Source marks on hypothetical outcomes.** A marks only reported outcomes, and with an invented mark. B and C mark hypotheticals "inferred". Classification: **ambiguous guide wording**.
8. **Kind of a partial outcome.** B uses "hoped for", C uses "hoped for in part", and A gives none. Classification: **ambiguous guide wording**.
9. **Whether failing to agree rules withdraws the family's agreement.** Only A addresses it. **Unresolved**.
10. **Affordability dream.** A and B include one; C keeps to the three stated wants. Classification: **legitimate alternative** (the author questions show the guide's dream test left this open).
11. **Waiting-list fix.** Only C writes one. **Legitimate alternative**.

### Guide changes, each tied to a disagreement

- Add: "A hoped-for outcome can't go beyond the intended result. Anything after completion belongs to another fix or to the downstream benefit." This would have prevented B's Fix 2 and Fix 6, C's Fix 8, and C's Fix 5 title (disagreements 1, 3, and 4).
- For decisions made by someone else, say: "If someone else decides, the intended result can be 'decision received'. Approved and refused are its outcomes, and the steps are a checklist." This would have prevented disagreements 1 and 2.
- Add: "Don't turn silence into yes either. A related arrangement doesn't establish a schedule." This would have prevented disagreement 5.
- Add: "A request awaiting an answer is a pending outcome. Write the related facts as 'agreed: no' and 'refused: no', and use only yes, no, or not checked." This would have prevented A's F21.
- Add: "An outcome establishes only what it says. A 'likely' outcome can't set a fact to yes." This would have prevented A's Fix 1.
- Say whether hypothetical outcomes take a source mark, and if so which one. This would have prevented disagreement 7.
- Say: "A partial outcome takes one kind for its part." This would have prevented disagreement 8.
- Add: "A failure in a later fix doesn't withdraw an earlier outcome that is still true." This would have settled disagreement 9.

## Five-line summary

1. Conclusions the graphs support correctly: the manager's reply is pending and not an agreement; only Tuesday has known cover; eligibility is not approval; joining the swap alone is not cover; no dream is reached; Mom stopping turns her fact to "no"; A and C handle the reversal on both fixes.
2. The most common unsupported inference is promoting a weaker signal to a firm yes or to cover: "likely eligible" becomes eligible (A), "share agreed" becomes care on agreed days (B), and "Mom covers Tuesday" becomes Tuesday is a workday (C).
3. The guide change most likely to help: "A hoped-for outcome can't go beyond the intended result; when someone else decides, the result is 'decision received', and approved and refused are its outcomes."
4. The authoring burden was 15–45 minutes per author, with the most effort spent where to cut each fix to one activity, followed by per-day "not checked" noise and source marks for silence and for hypothetical outcomes.
5. Round 3 should test a situation with a partly known schedule (to check silence becoming yes and per-day facts), a decision made by a third party, partial outcomes, a need that goes unmet later (like funding), and a reversal that follows from a recorded outcome, using the revised guide wording.
